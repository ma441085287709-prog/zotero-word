# macOS 桌面连接

稿件处理由本机 Python 连接已安装的 Word 与 Zotero。Word 通过 Apple 事件打开、保存和关闭工作副本。Zotero 通过自带的 MacWord 集成读写引文字段。读取个人文库时优先复用本次已建立的原生会话。尚无会话时，入口通过本机 API 每页读取 100 条。指定其它库时可提供已绑定的实际库快照。

首次连接时，macOS 可能提示宿主控制 Word、Zotero 或 System Events，或提示 Zotero 控制 Word。按出现的应用名称处理「隐私与安全性」中的自动化或辅助功能权限。保留系统拒绝的原始错误，使用已有授权继续。

本机 API 的连接与套接字读超时为 3 秒。一轮读取最多重试一次临时断开的 GET，只重读失败页。API 关闭、连续超时或未取得完整且身份一致的数据时，入口丢弃该次部分结果，自动交给原生读库。该任务目录的 `read-connection.json` 记录页起点、重试、HTTP 状态或传输错误。`library.json` 只记录完整读库结果。

正式任务从宿主已有桌面执行权限的上下文启动。原稿解析和文献匹配完成后，入口在首次打开工作副本时连接 Word。Zotero 接受原生任务后写入 `started.json`，其中的任务、会话、操作和目标文件须与请求一致。每次打开工作副本，Word 和 Zotero 重新核对当前文件与选中引文。

桌面任务出错时，`diagnostic` 指向该次错误记录，包含失败阶段、系统或脚本报错及当时已读到的进程和窗口信息。菜单、焦点等问题在恢复桌面状态后可续办。遇到脚本类型错误应先修正对应代码。已发出执行命令但缺少确认时，先核对该任务的回执与磁盘文件。

用户只要求方案、改代码或打包时，保持应用和稿件原状。另行请求集合导入或成员变更时，按[文库执行说明](library-execution.md)绑定文库和授权。
