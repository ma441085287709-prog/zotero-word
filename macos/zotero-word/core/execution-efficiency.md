# 同次执行复用与性能边界

日常稿件从统一运行入口开始或恢复，由真实输入和已保存状态决定处理路线；新引用默认采用 [混合批量写入](hybrid-citations.md)，模型做证据与歧义判断，脚本做已确认位置的重复写入。本轮动态引文以 Zotero 的刷新结果和 Word 对工作副本的保存、关闭回执为准。集合与排版按另行请求核对。阶段推进及锁见 [运行控制](run-flow.md)，真实库执行见 [库操作执行](library-execution.md)。不以吞掉错误、少查引用或跳过刷新后的结果核验来提速。

## 可以复用的计算

`core/scripts/state_cache.py` 提供仅当前 Python 进程内有效的 `Memo`。它只接受两种可信纯函数结果：

| 调用 | 复用内容 | 每次 lookup 的绑定 |
| --- | --- | --- |
| `memo.inspection(document, inspector)` | 已保存 DOCX 的完整解析 | 绝对路径、实际文件字节哈希、实现代码、计算函数身份 |
| `memo.layout_expected(document, profile, role_map, compute)` | A 源稿的纯预期格式计划 | 上述绑定及格式规则/角色图实际内容 |

`inspector` 是原始完整解析函数；`compute` 是原始 `_expected`，调用参数保持原样。两者须是本进程已加载的可信稳定函数，不能指向返回旧回执的文件读取器。规则和角色图可为其原生支持的文件路径或 JSON 对象。默认代码绑定覆盖核心 Python 和 JavaScript 文件；文件增加、删除或内容改变都会使旧键失效。

命中返回深复制，防止调用者修改结果后污染下次读取；缓存内部指纹或必要字段损坏时丢弃重算，重算失败则 HOLD。计算期间源稿、规则或代码变化时拒绝该结果，先重查保存状态。缓存不加载磁盘结果，没有 pickle/eval 或反序列化代码路径；摘要仅含计数，不能作为验收凭据导入。

当前没有跨 CLI 进程的解析缓存。下一次命令或应用重启从空 memo 开始；恢复复用的运行记录和确认仍按各自原有绑定重新检查，不能因此宣称解析已命中。运行期间记录 `hits` / `misses` / `invalidated`，没有观测就不报告提速比例。

## 永远重新观察的状态

- 实际库、集合成员、未知写入结果及目标条目身份；计划、旧导出和缓存解析不能充当新鲜观察。
- Word 当前任务、实际原生刷新与保存关闭结果。专项排版另记页面观察。缓存不证明刷新完成，也不代替真实用户答复。
- 常规引文交付采用刷新回执中的全部域和书目结果，保留原稿保护。逐页检查、独立 CSL 复算、References 八项外观和全文排版验收按各自的专项委托执行。

例如 B 经 Word 保存后，必须读取新保存的 B 字节并检查实际结果；B 的路径相同不代表内容未变。A 保持不变时可以复用 A 的解析和纯预期计划，再与新 B 比较；不得复用旧 B 的结果、旧最终 PASS 或旧页面观察。格式覆盖仍是所有目标角色及所有普通段落，而不是只抽查被修改的段落。

## 模型与工具往返

已有 DOI/URL 查询去重、已核实活动域复用、未知写入先重查、集中一次必要 Refresh 以及 A/B 隔离继续沿用。此次同次执行 memo 不把这些既有规则算作新增能力。

模型优先读结构化摘要、实际阶段、待确认项及下一动作；完整证据留工作目录，不逐条回传整库或全稿 XML。可并行独立只读查询，写入依赖和单一桌面操作按实际顺序执行。

新引用一次建立绑定当前源字节的准确范围→真实 URI 映射并预检全部条目。使用受限写入器输出独立副本与简短回执，然后集中原生验证；不让模型循环生成临时锚点、逐处删除和搜索。原生 UI 只读取判断当前动作所需的窗口/对话框，不为每处引用输出全篇正文。

没有可用批量能力或有不支持范围时，报告具体位置和能力缺项，继续独立可做的核查。需要切换到少量原生插入时明确说明范围和原因；不得把大量逐处 UI 伪装为批量执行，也不靠生成更多计划掩盖未执行动作。

记录耗时和工具次数，区分解析、文献查询、导入、原生更新、保存关闭与人工等待；无法分摊写未知。纯函数缓存测试只证明重算减少，不证明 Word 或 Zotero 原生刷新更快，更不能承诺百篇新增引用的完成时间。

## 混合写入的衡量

按输入位置数记录计划/预检/写入耗时、原生操作次数、读取界面次数及保存检查点。比较相同稿件/环境的实际观测；没有 token、CPU 或等待分项数据就记未知。批量字段副本的 `PENDING_NATIVE_VALIDATION` 不参与完成数量统计；只有原生验收与全覆盖核验通过后计入 A 成果。原生识别失败或源稿变化时恢复检查实际保存状态，不重放旧计划。
