# macOS 适配范围

Codex 与 DeepSeek Harness 的本地执行入口、原稿保护和验收逻辑相同。使用[注册表](registry.json)定位本版本代码。桌面身份来自 Word 的工作文件路径、选中引文字段和 Zotero 的文档句柄。

[运行记录](../core/run-flow.md)中分别保存原稿与工作副本的指纹、Zotero 刷新后的引文和书目条数，以及 Word 的保存和关闭回执。只有实际完成的阶段可以写为完成。文库集合、论据、视觉审查及全文排版按用户请求独立执行。

2.4.0 所用的 macOS 引文流程已在一次本机运行中完成 Zotero 刷新、Word 重开和真实条目抽查。每份客户稿件的完成范围以该任务的回执为准。[版本记录](../release-status.json)
