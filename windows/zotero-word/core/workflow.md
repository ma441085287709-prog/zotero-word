# Windows 稿件处理

动态引文任务由[正式运行入口](run-flow.md)负责。每个明确的 DOI 或链接按唯一文献匹配。作者年份、静态编号和歧义项集中到待匹配表，保留每个位置与真实 Zotero URI 的对应关系。源稿、快照和写入边界见[原稿保护](execution-guard.md)。

在独立副本上批量备妥兼容引文字段。Zotero 在绑定文档内应用实际样式，按需生成动态书目，刷新引文。Zotero 读回全部引文字段并核对文库条目和书目。Word 确认保存并关闭同一份副本，正式入口把文件路径和指纹写入 `COMPLETE` 回执。

用户另行要求整理稿件集合时，按照[集合与基准](manuscript-state.md)计算实际增删差集，只更新获准的集合。另行要求核对 CSL 细节、字体或论文论据时，使用[专项工具](script-commands.md)。用户明确选择继续全文排版时，从引用完成稿另存排版副本，见[全文格式](optional-layout.md)。
