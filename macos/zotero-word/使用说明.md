# zotero-word 2.4.4  mac 使用说明

用桌面助手将 Word 稿件中的引文与 Zotero 文库条目匹配，按目标期刊的样式生成可编辑的动态引文和参考文献表。处理在独立工作副本上进行，原稿保留。

## 在 Mac 上开始

1. 在同一台 Mac 的同一登录账户使用桌面版 Microsoft Word、Zotero 和能执行本机命令的助手。Word 中应能看到 Zotero 选项卡，目标期刊的 CSL 样式应已安装在 Zotero。入口会寻找本机带有 `lxml` 的 Python 3.10 或更高版本。
2. 使用 Codex 时，在独立项目下创建 `.agents/skills/`，把解压得到的整个 `zotero-word` 文件夹放进去。目标下已有同名文件夹时，选一个新项目以保留现有安装。最终路径应为 `试用项目/.agents/skills/zotero-word/SKILL.md`。在 Codex 中打开这个项目。[Codex 本地技能目录](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)
3. 把要处理的 `.docx` 添加到该项目的对话，指定期刊并发送下面的请求。可在请求中直接指定本项目内的 `SKILL.md`。

> 请用本项目的 $zotero-word，按 Environmental Science & Technology（ES&T）的样式整理这份 Word 稿件的动态引文和参考文献表。保留原稿，Zotero 刷新成功、Word 保存关闭后，把这份工作副本给我。

其他期刊可提供已安装样式的 Zotero 样式链接。希望把核实后的缺失文献加入个人文库时，请在请求中明确授权。使用 DeepSeek Harness 时，可让具备本地执行能力的会话直接读取解压目录中的 `SKILL.md`，运行时使用同一套 Mac 入口。

首次调用时，按 macOS 提示为实际运行的桌面助手授予所需的自动化或辅助功能权限。Zotero 的“执行 JavaScript”窗口由连接器打开并输入代码。如果此前自己打开了这个窗口，请先保存里面需要保留的内容并关闭该窗口。

## 取回文件或继续任务

- 收到 `COMPLETE` 后，打开助手交付的 `.docx`。回执中的 `document` 指向 Zotero 实际刷新、Word 已保存并关闭的同一份文件。可以在 Word 中点选一处引文，用 Zotero 的 `Add/Edit Citation` 查看对应条目。
- 收到 `NEEDS_MATCHING` 时，按助手列出的位置确认有歧义的文献。收到 `HOLD` 时，保留工作目录，按具体错误处理后让助手“从上次的运行目录继续”。
- Word 保存或关闭中断时，告诉助手“从原运行目录继续”。已有 Zotero 刷新回执时，助手只续办保存或关闭。若 Word 等待文件访问授权，处理当前提示后继续。
- 向提供方反馈问题时，可提供本包版本、Word 和 Zotero 版本，以及回执中的 `stage`、`reason_code` 和简短错误信息。

若提示 Python 缺少 `lxml`，可以让助手在项目虚拟环境中安装 `lxml`，使用该环境的 Python 调用包内入口。同一任务继续使用运行目录内的工作文件。[续办说明](core/run-flow.md)

发送刷新任务前，如果 Zotero 失去前台，连接器会自动唤回一次。刷新任务的 `native-*/attached.json` 记录实际执行的原生脚本版本。

`native-*/refresh-target.json` 的 `refreshTiming` 记录脚本版本、样式确认、首选项返回和字段读取完成的 UTC 时间。`writeErrors` 列出分步写入 `refresh-timing.json` 时的异常。设置已匹配时，`setDocPrefsRequired` 为 `false`，首选项返回时间为空。原生刷新发生错误时，`error.json` 保留当时已取得的计时信息。

DeepSeek 在刷新前被 Word 拒绝打开副本时，会给出该副本的路径和续办命令。准备好可控制 Word 的本机助手后，把命令交给它执行即可。原稿可以保持打开。本次修订仅做静态核对。
